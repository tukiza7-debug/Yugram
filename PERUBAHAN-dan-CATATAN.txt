---------------------------------------------------------------
1. PERBAIKAN UTAMA: GAMBAR / AVATAR TIDAK MUNCUL
---------------------------------------------------------------
Penyebab: TDLib hanya mengisi `File.local.path` SETELAH file di-download.
Kode lama tidak pernah memanggil downloadFile, dan event `UpdateFile`
tidak di-handle → path selalu kosong → Coil tidak pernah load gambar.

Yang diubah:
- TDLibClientManager.kt  : tambah `fileFlow` (SharedFlow<TdApi.File>)
                           + handler `UpdateFile.CONSTRUCTOR`
                           + method `downloadFile(fileId, priority)`
- TelegramRepository.kt  : expose `fileFlow` + `downloadFile()`
- ui/components/TdImage.kt (BARU): composable yang memicu download
                           dan reaktif terhadap fileFlow.
- ChatListScreen.kt      : avatar chat → pakai TdFileImage.
- ChatRoomScreen.kt      : foto pesan & thumbnail video → TdFileImage.

4. CATATAN / KETERBATASAN YANG MASIH ADA (belum diubah)
---------------------------------------------------------------

---------------------------------------------------------------
5. CARA BUILD DI TERMUX
---------------------------------------------------------------
- Butuh JDK 17 + Android SDK (platform android-36).
- Set API credentials di gradle.properties:
    TELEGRAM_API_ID=...
    TELEGRAM_API_HASH=...
- Build: ./gradlew assembleDebug
  (atau assembleRelease jika ada signing config)
